# RAN KPI Analysis

## About This Project

This project demonstrates the analysis of 4G LTE Radio Access Network (RAN) performance using Python and Pandas.

The objective is to identify network performance issues, analyze key radio KPIs, and provide practical optimization insights.

## Key KPIs

- PRB Utilization
- DL Throughput
- UL Throughput
- CQI
- EUT
- Payload
- Cell Availability
- Traffic

## Analysis

The analysis includes:

- KPI distribution and trends
- Identification of worst-performing cells
- High PRB utilization analysis
- Throughput performance analysis
- KPI correlation
- Identification of potential performance issues
- Optimization recommendations

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Note

The dataset used in this project is simulated/anonymized and does not contain confidential operator data.
